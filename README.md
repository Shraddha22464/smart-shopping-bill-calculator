# Smart Shopping Bill Calculator 🛒

A beginner-friendly Python project that generates shopping bills and calculates discounts automatically.

## Features
- Takes customer name.
- Accepts product name, price, and quantity.
- Calculates individual product totals.
- Supports multiple products.
- Gives a 10% discount on bills of ₹1,000 or more.
- Generates a final shopping receipt.

## Python Concepts Used
- Variables and Data Types
- User Input
- Type Conversion
- Arithmetic Operators
- If-Else Statements
- While Loop
- Break Statement
- F-Strings

## How to Run

```bash
python shopping_bill.py
```
